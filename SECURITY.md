# Security

Version 0.1.x receives security fixes. Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/KanadeK/bundle-drill/security/advisories/new).
If unavailable, open an issue asking for a private channel without posting details.
Use synthetic inputs. Never publish tokens, private targets or private Git objects.

This utility is an audit aid, not a security certification or malware sandbox.
See README for its exact scope and resource limits. Use an up-to-date Python and,
where applicable, Git. A hostile local process that can rewrite inputs or runtime
binaries is outside the threat model.
